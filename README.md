# Recorrido Canal

Aplicación de campo para el reconocimiento de estructuras existentes en canales de riego:
fotografías georreferenciadas (UTM), ubicación sobre el KMZ del canal, cadenamiento,
y reporte en Word y KMZ. Funciona sin señal una vez instalada.

**Instalar en iPhone:** abre la dirección de GitHub Pages de este repositorio en Safari →
Compartir → *Agregar a pantalla de inicio*.

Los recorridos, fotos y reportes se guardan solo en el teléfono; este repositorio contiene únicamente el programa.
